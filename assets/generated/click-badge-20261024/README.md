# Egg "Click" badges (October 24, 2026)

Stevin asked for the egg click badge to look 1:1 like Drop a Fruit's (his screenshot: a tan
lumpy blob with a white outline, a dark mouse with a light left button, "Click" under it).
Made with the Codex CLI image tool from crops of that screenshot; the word is drawn by the
game (`EggView` "Word" label, input-specific: Click / Tap / R2).

| File | Roblox asset | Used for |
|---|---|---|
| click-badge.png | rbxassetid://79756670832324 | keyboard/mouse (`EggView.CLICK_BADGE`) |
| tap-badge.png | rbxassetid://76701185375129 | touch (`EggView.TAP_BADGE`) |
| mouse-icon.png | rbxassetid://121385630700970 | fallback icon inside the frame blob (`EggView.CLICK_ICON`) |
