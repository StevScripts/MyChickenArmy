# My Chicken Army loading logo

The three-chicken wordmark used by `src/client/LoadingController.luau` is uploaded to the game's creator group as Roblox image asset `109846889640981` (`rbxassetid://109846889640981`). The original 1024 × 683 transparent PNG and the 512 × 342 upload version are kept here as editable asset records.

The loading screen places this logo over a blurred aerial orbit of the actual island. It preloads opening UI, audio and nearby plot assets, and dismisses after those requests finish and the server reports a ready player profile. Skip Loading appears after seven seconds and bypasses the remaining asset wait; the profile must still be ready. No baked-in background scene is part of the image.
