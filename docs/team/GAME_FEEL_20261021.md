# Game feel pass — October 21, 2026

Stevin's request (verbatim intent): "make sure that every single little interaction
from the UI to the game to everything is very animated with really nice VFX and sound
effects, MAKE SURE EVERYTHING is RESPONSIVE". This document is the contract for that
pass: the shared vocabulary every screen uses, the sound-cue catalog, who owns which
files, and how the result is verified. It supersedes nothing about rules or economy;
it only adds presentation.

## 1. Principles

1. **Every action answers at once.** A press, hover, focus, claim, buy, pickup, hit
   or arrival gets visible motion within one frame and a sound within 100 ms. Server
   confirmation then adds the *reward* feedback (count-up, burst, jingle). Never wait
   for the server to show the press itself.
2. **One vocabulary.** Use `UIMotion` (screen), `ScreenFeel` (camera) and `WorldFeel`
   (world) below. No private tween frameworks, springs or frame loops; a plain
   TweenService tween is the tool (AGENTS.md › Simple animations). Reuse the
   existing module when it already does the job (CoinBurst, CombatEffects,
   RollCamera, NotificationFlair).
3. **Budgeted, not noisy.** One emphasis per event (DESIGN.md §11 feedback budget):
   a reward is *one* of confetti / flash / burst plus a sound, not all five. Helpers
   cap counts per parent and per world area; respect them, do not bypass them.
4. **Reduced motion is honoured** (Settings › Reduced motion → `app.reducedMotion`,
   `Theme.Motion.reduced`). Helpers already skip or settle; new code must not loop,
   travel or shake under it, but must still show the state change.
5. **One layout for every device.** Scale geometry, aspect constraints, TextScaled;
   no PreferredInput/TouchEnabled branches for positions or sizes (AGENTS.md › UI Lab
   rule). Touch only changes *budgets* (fewer particles), never layout. Hover-only
   feedback always has a tap/focus twin. Hit targets stay ≥ 48 px.
6. **Glossary and rules unchanged.** Coins (never "$"), Army, Flock, Upgrades,
   Missions, Rebirth N. No gameplay, price, odds, save or server change in this pass.
   Server files are off limits.
7. **Sounds come from the Studio library.** Code plays cue names; the Sound objects
   live in `SoundService.MyChickenArmyAudio` (Studio-owned, edited by the lead with
   the recipe in §3). A missing cue is silent, never an error: `audio:Has(name)` lets
   code fall back to an existing cue.

## 2. Shared API (built October 21 on main)

### `client/UIMotion.luau` (`Theme.Motion`) — additions
| Call | What it does |
| --- | --- |
| `Motion.Ease.Pop/Snap/Soft/Bouncy/Enter/Leave` | Named `{style,direction}` pairs so screens ease alike. |
| `Motion:Point(parent, Vector2)` / `Motion:CenterOf(item)` | Absolute pixels ↔ Scale UDim2 inside a parent (for Fly/Float). |
| `Motion:Punch(item, amount=1.18, seconds=0.3)` | Emphasis pop through UIScale (value changed, badge appeared). |
| `Motion:CountTo(label, value, format, seconds=0.45, {tick=fn, tickGap=0.06, punch=1.12, punchTarget, fallSeconds})` | Count-up with a punch on gains and a throttled tick callback; spends drop at once. |
| `Motion:Stagger(items, each(item,index,delay), gap=0.04, window=0.45)` | Staggered sequence with `cancel()`; the last starts within `window`. |
| `Motion:Reveal(container, {from=0.7, seconds=0.26, gap=0.035, window=0.4, limit=40, each})` | Grow a container's visible children in one after another (menus, grids, rows). |
| `Motion:Flash(item, color, seconds=0.35, peak=0.55)` | Colour wash overlay on an item. |
| `Motion:Float(parent, text, position, {color,size,seconds,rise,font,stroke,limit})` | Floating "+12" text that pops, rises and fades. |
| `Motion:Fly(parent, asset, from, to, {size,seconds,arc,spin,onArrive,limit})` | Image flies A→B in an arc (coin into the HUD, chicken into the Army count). |
| `Motion:Confetti(parent, {count,origin,spread,seconds,colors})` | UI confetti (28 desktop / 16 touch). |
| `Motion:Ripple(item, color)` | Expanding press ring. |
| `Motion:Glow(item,color,thickness)` / `StopGlow` | Pulsing "ready" stroke (steady ring under reduced motion). |
| `Motion:Bob(item,amount,seconds)` / `StopBob` | Up/down attention bob. |
| `Motion:Wobble(item,degrees,seconds)` / `StopWobble` | Side-to-side rotation wobble. |
| `Motion:Slide(item, from, to, seconds, ease)` | Position slide with a named ease. |
| `Motion:Progress(bar, fraction, seconds, flashColor)` | Tween a fill bar; gains flash it. |
| `Motion:Settle(item)` | Stops breathe/glow/bob/wobble before hiding. |

Existing and still the first choice: `BindButton` (hover/press/shine on every
`Theme.Button`/`IconButton`), `PopScale`, `Pop`, `Shake` (the "no"), `Breathe`,
`Appear`, `Shine`, `OpenPanel`/`ClosePanel`, `Toast`, `Count`, `Spin`, `Burst`.

### `client/ScreenFeel.luau` (`app.screenFeel`)
`Shake(strength 0.1–0.6 studs, seconds)`, `Flash(color, strength 0–0.6, seconds)`,
`Zoom(degrees, seconds)` (FOV punch; skipped while the roll camera holds the FOV),
`Impact(size 1–3)`, `Celebrate(color, size 1–3)`. Camera stays with the player.

### `client/WorldFeel.luau` (`app.worldFeel`)
`Burst(position, {color,count,size,speed,spread,lifetime,gravity,light,texture})`,
`Ring(position, {color,radius,seconds,thickness})`, `Poof(position, {color,count,size})`,
`Sparkle(part, seconds, {color,size,rate})`, `Highlight(modelOrPart, color, seconds)`,
`Text(position, text, {color,size,seconds,rise,coin=true})`, `Sound(name, position,
pitch, options)`, `Celebrate(position, color, size 1–3)`. Budget 28 desktop / 14 touch
live effects within 120 studs; reduced motion keeps only `Text` (no rise).

### `client/AudioController.luau` — additions
`audio:Has(name)`; `audio:PlayAt(name, position, pitch, options)` (spatial one-shot);
`Play` option `pitchVariance` (e.g. 0.06) for cues that repeat.

## 5. Hand-off and verification

Every session: commit on its branch; run the analyzer on each changed file against a
`git archive HEAD` baseline (memory: `local-luau-checks`); run
`/Users/stevin/Documents/Projects/MyChickenArmy/.tools/rojo build default.project.json -o <scratch>/x.rbxlx`;
then report branch, commits, files, cues used, hooks needed in hot files, and what
to playtest. The lead merges in id order, runs the sound recipe in Studio, playtests
in Pet Roll Test (Studio Flow) with screenshots, renders the UI Lab stories at PC /
Phone / Tablet, and fixes anything that overlaps, clips or falls under 48 px.
