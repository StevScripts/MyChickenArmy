## How the visuals work

- **Where the mutation comes from.** `SpecialChickenVFX` reads the model attribute `Mutation`. If that attribute is missing, it falls back to the local player's own snapshot, matching the model's `PetId` and `OwnerUserId`. So the player's own yard and army chickens show the effect today with no server change. Other players' chickens and battle-spawned rigs need the server attribute (requests 1 to 3).
- **Look.** Each tint multiplies the authored `SurfaceAppearance.Color`, or `Part.Color` for untextured parts, and is restored exactly on clear. Textured MeshParts without a SurfaceAppearance can't be tinted and only get particles.
  - Golden: warm gold tint and gold Glitter sparkles.
  - Rainbow: the hue cycles while the chicken is near and visible, with rainbow-colored Glitter. It holds a fixed pink-violet tint when the chicken is far away or reduced motion is on.
  - Shadow: darkened purple tint and a thin purple-black Smoke aura emitted from the body's bounds.
  - Cosmic: blue-violet tint that shimmers while visible, Star twinkles locked to the body, and two Star emitters orbiting the body.
- **Motion.** Every loop runs off a shared `NumberValue` driven by a repeating linear TweenService tween, one per loop name. Chickens copy the value on the existing 20 Hz update, the same pattern `FlowingChickenTexture` uses.
- **Budget and settings.** Particles follow the existing visibility rules: reduced motion, Defeated/PresentationHidden, transparency, and the `ChickenEffectQuality` cull distance. Beyond the cull distance only the tint stays. A module cap allows at most 24 mutated chickens to run particles at once. Chickens over the cap keep the tint and claim a slot when one frees up.
- **Giants.** Particle size, speed and orbit radius scale through the existing body-height `unit`, which is clamped to 4 as before.
- **Badges.** `Special.Badge(parent, id, name?, text?)` is a dark rounded tag with a stroke and the name in the mutation's color, with a gradient for Rainbow. Labels use `Theme.Label` and `Theme.ScaleText`. The card corners are rounded on purpose, because the worker doc asks for a rounded tag.
- **Roll reveal.** A BillboardGui sits above the revealed chicken and pops in 0.3 s after landing (a TweenService Back tween on a UIScale). Rainbow and rarer also get a colored flash (a tween on a frame behind the tag), a podium sparkle burst in the mutation color, and the `RollRare` sound. Golden gets a small `Pop` sound. With reduced motion the tag appears without any animation.

## Tests: `tests/MutationChecks.luau`

Run in a fresh Run-mode server: `require(game.ServerStorage.PetRollTests.MutationChecks).Run()`. It returns `{name, passed, error}` entries and prints PASS/FAIL lines.

1. `IsValid`, `Multiplier`, `Rank` and the Defs values for every id, nil and unknown ids.
2. `Roll` makes one draw per unlocked check, rarest first. Junk ranks count as 0. A fixed seed repeats.
3. Seeded rates:
   - Rank 5: 2,000,000 rolls, each mutation within 15% of its chance. The expected count accounts for a rarer mutation being checked first.
   - Rank 0: 200,000 rolls, Golden only.
   - Rank 4: no Cosmic.

   **I used 2,000,000 rolls instead of 200,000 on purpose.** At 200k, Cosmic expects only 40 hits, and a 15% band is about 1 sigma, so the check would fail about a third of the time. At 2M the band is about 3 sigma. Expect 1 to 3 seconds; the loop yields every 250k rolls when it can.
4. `Best` picks the highest multiplier and accepts holes, `false`, junk ids, `{}` and nil.
5. A Golden chicken earns 1.5× a plain one in `PetIncome`, `DisplayedPetIncome` and the snapshot's `eggsPerSecond`. The offline rate rises by exactly 1.25× for a one-plain-plus-one-Golden flock. Combat stats are unchanged.
6. With `Golden.chance = 1`, every rolled offer carries Golden, and buying one keeps it.
7. Fusing Golden + plain + Rainbow makes a Rainbow Giant. Three plain inputs stay plain.
8. A save round trip keeps a mutation. A saved `"Nope"` loads as no mutation, and the profile and every chicken still load.
9. A Galaxy Crate chicken has no mutation, even with `MutationCatalog.Roll` patched to always return Cosmic. I confirmed `CrateService:Open` calls `AddPet(species,1)` with no mutation.

## How to force a mutation for testing

- **Server command bar (Run mode):**
  - `require(game.ReplicatedStorage.PetRoll.Shared.MutationCatalog).Defs.Golden.chance = 1` makes every non-starter offer Golden.
  - For the others, set the def's `unlockRank = 0` and `chance = 1`, for example `Defs.Cosmic.unlockRank = 0; Defs.Cosmic.chance = 1`. Rarest wins, so set only one at a time.
- **On an owned chicken:** set `session.pets[id].mutation = "Shadow"` on a disposable session and send any request so a new snapshot goes out.
- These are local edits. Never commit them.

## Performance notes

- Unmutated chickens cost one extra `GetAttribute("Mutation")` per frame. If the local player owns a mutated chicken, chickens without the attribute cost two more reads.
- Mutated chickens rescan their descendants for tint targets once a second. Rainbow and Cosmic rewrite their tints at 20 Hz only while visible.
- At most 24 chickens run mutation particles at once. Each runs 1 to 3 low-rate emitters (3 to 9 particles/s).
- Changing a mutation rebuilds that chicken's effect record, the same way an appearance change does. This only happens on reveal or fusion.

## Unsure / please check in Studio

- `SurfaceAppearance.Color` should multiply the color map with these rigs' AlphaMode. Reads and writes are wrapped in `pcall`, but if the tint doesn't show, the fallback would be a Highlight. I avoided Highlight because of the 31-highlight limit.
- Shell emitters (Shadow aura, Cosmic twinkles) are parented to the body MeshPart with `Shape = Box`. Check that the aura reads as "thin" on the T-pose bounds, and tune `Rate`/`Transparency` in `_attachMutation` if it looks heavy.
- The roll tag height uses the preview's `VisualHeight` attribute plus 1 stud. Check it on a Giant-sized species if one can appear on the podium.
- The Index (`IndexBrowser.luau`) is per species and not an M1 file, so it has no badge. Showing a badge there would need a saved per-species "mutations discovered" record, which is a design call.
