# Follow-up measurement plan — not activated

First measure fresh F2P sessions using the implemented $150M/$300M/$500M late
ladder. Record active time at each slot purchase, cash earned/spent, income
upgrade levels, time collecting/selling, owned/deployed flock and fusion/army
spending. Exclude offline time from the 8–9-hour target and record paid benefits
separately. Only compare players with eight physically available podiums.

Compare median and slower completion times, plus players who stop before each
slot. Do not report only successful completers: expensive goals can cause dropoff.
Check whether a long slot-5-to-6 wait persists and whether all-eight completion
falls near the requested target under observed collection and spending patterns.

If actual sessions run too long, test late prices at 80% ($120M/$240M/$400M).
If they run too short, test 120% ($180M/$360M/$600M). Keep slots 2–5 and all other
economy parameters fixed to distinguish the price effect. These bounds are
candidate experiments, not implemented prices or predicted outcomes. Do not
revoke existing owned slots; compare new purchases only. Calibrate the model
with observed behavior before choosing another ladder.
